# Franco Durán · portfolio

Página estática de una sola página, sin build. Publicada con GitHub Pages en https://francoduran23.github.io/francoduran/

- `index.html` · estructura
- `styles.css` · sistema visual tomado de [Cole Juy](https://colejuy.vercel.app): tokens por rol, Barlow, escala de espaciado 4–32, radios 24 → 8, sin sombras; modo oscuro automático
- `app.js` · todo el contenido (ES y EN) en `T`, los links en `LINKS` y las marcas en `BRANDS`. Editá ahí.
- `assets/` · foto, logos de proyectos y marcas de jujuy.dev; `fonts/` · Barlow (OFL)

Íconos de Solana y Stellar: [Simple Icons](https://simpleicons.org) (CC0).
